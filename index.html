💡 ¿Qué es MoviPass?

MoviPass es un proyecto web desarrollado de manera colaborativa en el ámbito universitario. Busca facilitar la gestión de cooperativas, unidades de transporte y funcionalidades relacionadas con los buses. Esta página presenta el trabajo; no es el sistema completo.

🎯 Objetivo: desarrollar una interfaz fácil de utilizar y conectarla con servicios que permitan administrar la información del transporte de manera organizada.

✨ Funcionalidades del proyecto

Áreas en las que trabaja el equipo; algunas todavía están en desarrollo.

🏢

Cooperativas

Interfaces para registrar, consultar, editar y eliminar información de cooperativas.

🚌

Buses

Gestión de datos de unidades, como placa, tipo de bus, chasis y carrocería.

💺

Asientos

Diseño de distribuciones de asientos para buses de uno y dos pisos, con categorías normales y VIP donde corresponda.
